# 💧 Hydrate — Landing Website (`tryhydrate.app`)

Modern, high-converting landing website for **Hydrate**, the lightweight menu bar and system tray hydration tracker for macOS and Windows.

Live at: [https://tryhydrate.app](https://tryhydrate.app)

---

## 🚀 Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom Glassmorphism & Animations
- **Icons**: Lucide React + Canonical Brand SVGs (Apple, Windows)
- **Animations**: Framer Motion + Canvas Confetti
- **Deployment**: Static SPA (`dist/` output for GitHub Pages, Vercel, Netlify, Cloudflare Pages)

---

## 🛠️ Local Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Dev Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
